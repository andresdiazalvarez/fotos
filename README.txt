FOTOS PARA GITHUB PAGES

1. Crea un repositorio nuevo en GitHub.
2. Sube TODO el contenido de esta carpeta a la raíz del repositorio.
3. En GitHub abre Settings > Pages.
4. En "Build and deployment", elige "Deploy from a branch".
5. Selecciona la rama "main", carpeta "/ (root)" y pulsa Save.
6. GitHub mostrará el enlace de la aplicación cuando termine.

Importante: no subas el ZIP como un único archivo. Descomprímelo primero y
sube todos los archivos y carpetas que contiene.
